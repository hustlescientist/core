# CORE working brand reference

Source: supplied CORE brand guide, October 7, 2026. This is an implementation summary. Sampled asset colors are distinct from proposed interface, type, and messaging standards.

## Identity

Preserve the full-color orange CORE artwork, gray illustration, and "Powered by The Rogers Foundation" endorsement. Use the original artwork on white, preserve proportions, and obtain approved compact/reversed variants. The header and footer now use the original 800x242 CORE logo from the supplied archive. The exact archive label and filename are retained in the media register; the illustration, wordmark, and foundation endorsement are not reconstructed.

Existing lead message: **Every Student Has Potential. CORE helps them discover it.** New supporting copy in the locale files is draft content. Frame students as active participants and families as partners; avoid guaranteed outcomes, deficit labels, or invented testimonials.

## Typography and layout

Montserrat is a recommendation, not a verified original font. The CSS uses Montserrat if already available, otherwise Arial/sans-serif. No font is fetched or bundled. Approve a licensed loading approach separately.

Use strong headings, comfortable line height, a roughly 1,200-pixel content container, modest card rounding, and generous whitespace. Primary controls target at least 48 CSS pixels. Maintain readable mobile layouts and space for expanded Spanish text.

## Media and language

Use authentic, approved program photography. Do not present generated scenes as evidence of CORE activities. Verify permissions and youth consent outside Git. Supply meaningful EN/ES alternatives; keep essential instructions as text.

Treat English and Spanish as complete experiences. The current translation is a draft, including the suggested lead line "Cada estudiante tiene potencial. CORE le ayuda a descubrirlo." Consequential copy needs qualified review. Accessibility target: WCAG 2.2 AA, not a claim of conformance.
